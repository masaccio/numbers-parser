# Security Policy

## Supported Versions

Older versions are typically supported for security updates within 2 years of release. As of writing this Policy, that is:

| Version  | Supported          |
| -------- | ------------------ |
| >=4.13.1 | :white_check_mark: |
| others   | :x:                |

## Reporting a Vulnerability

You can report a vulnerability privately to the author at python@figsandfudge.com. You should expect an acknowledgement
within a 1 week which will include an indication of when vulnerability will be analysed and fixed.
